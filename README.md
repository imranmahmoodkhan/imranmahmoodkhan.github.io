# Imran Mahmood Khan academic homepage

Personal academic website of Imran Mahmood Khan, Assistant Professor in Smart Food at the University of Nottingham Ningbo China.

Website address: https://imranmahmoodkhan.github.io/

## Contents

- Biography, research, projects, education, mentoring, academic service and contact information.
- Searchable publication list with article links and BibTeX citations.
- Portrait and credited publication figures in `assets/`.

## Updating the website

Edit `index.html` for profile information, `styles.css` for appearance, and `publications.js` for publication records. Keep the matching publication data in `data/publications.json` up to date. Place new publication images in `assets/papers/` and update `assets/publication-credits.html` with their sources.

GitHub Pages publishes the `main` branch from `/ (root)`. The `.nojekyll` file keeps the site as plain HTML, CSS and JavaScript. No build command or paid domain is required.

After saving an update, check the Pages deployment in the repository's **Actions** tab. Deployment changes can take a few minutes to appear.

Official deployment guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
